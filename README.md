# نسخه‌ی استاتیک سایت «رابطه‌ی عاشقانه» — برای GitHub Pages

خروجی خودکار `npm run export:static` از نسخه‌ی کامل Next.js (پیشوند مسیر `/rabete`، دامنه‌ی `https://lovelife4all.github.io`).

## چی داخلشه
- خانه، درس‌ها (+ جست‌وجوی سمت مرورگر و صفحه‌ی هر دسته)، **۱۲ تست تعاملی با امتیازدهی در مرورگر**، ریلزها، مشاوره (توضیح)، درباره، ۴۰۴
- فونت وزیرمتن و همه‌ی تصاویر به‌صورت محلی؛ `sitemap.xml`، `robots.txt`، `manifest.webmanifest`، تصویر OG
- `.github/workflows/pages.yml` برای انتشار خودکار

## محدودیت‌ها (نسخه‌ی استاتیک)
- ثبت‌نام/ورود، ذخیره‌ی نتیجه، تفسیر کامل اعضا، فرم‌های مشاوره و پنل ادمین فقط در نسخه‌ی کامل (Next.js + دیتابیس) کار می‌کنند؛ اینجا به صفحه‌ی توضیح هدایت می‌شوند.
- نتیجه‌ی تست فقط در مرورگر کاربر (localStorage) می‌ماند.

## به‌روزرسانی
از پوشه‌ی `web/` با سرور روشن روی پورت ۳۰۰۰: `npm run export:static` → این فایل را دوباره اضافه کن → `cd static-site && zip -qr ../rabete-github-pages.zip .` → آپلود در ریپوی `lovelife4all/rabete` (شاخه‌ی `main`، ریشه).
