# رابطه‌ی عاشقانه — نسخه‌ی استاتیک (GitHub Pages)

این پوشه خروجی خودکار `web/scripts/export-static.mjs` است و روی `https://lovelife4all.github.io/rabete/` منتشر می‌شود.

- بازسازی: در `web/` با سرور پروداکشن روشن روی :3000 → `npm run export:static`
- سپس این فایل را دوباره بسازید و زیپ کنید: `cd static-site && zip -qr ../rabete-github-pages.zip .`
- **ویژگی‌های سروری (ثبت‌نام، ذخیره‌ی نتیجه، رزرو مشاوره، پنل مدیریت) در این نسخه فعال نیست.** راهنمای استقرار نسخه‌ی کامل: `../DEPLOY.md`
